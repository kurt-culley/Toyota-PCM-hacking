# Bluetop ignition map in degrees

Generated by `python -m pcmre.readable --write` ([`../../analysis/pcmre/readable.py`](../../analysis/pcmre/readable.py)). Do not edit.

The base ignition map (`ign_base`, `$FF40` in 0642, `$FF5A` in 2860; identical in both) with:
- **load as a percentage**, and
- **each cell converted to degrees BTDC** with the ROM's own arithmetic.

Load is what the ECU calls `Load`: the airflow-meter pulse delay in µs, after the air-temperature correction.
On this airflow-meter ECU that pulse is the base fuel pulse, so it tracks **air per intake stroke** (LIKELY; grams per stroke are unknown until the SE056 is measured).
Here **100 % = 3072 µs, the map's top row**.

## How to read it

- **Full-load line:** the ECU clamps measured airflow at each rpm (`se056_max`), so load cannot exceed this percentage there. Cells in **(brackets)** lie above the line. They are only reached as interpolation targets, so they shape the timing just below full load but are never used as they stand. The line assumes a neutral air-temperature correction; cold, dense air raises measured load by up to about 11 % (`tha_corr`).
- **Rows in between:** the ECU interpolates in both rpm and load.
- **T-VIS:** the columns above 4350 rpm include **+2.8°** (+8 raw). The ROM adds it once T-VIS has opened [ROM:$F89F], after a short counter delay. The changeover has hysteresis: it opens rising past 4350 rpm and closes falling below 3950 rpm. So the 4000 rpm column gets the +2.8° only when coming down from above 4350.
- **256 µs lead:** the ROM fires every spark 256 µs earlier than the map angle [ROM:$F900]; the row shows what that is worth at each rpm. If the lead only cancels a hardware delay (igniter, NE filtering), the table above is the real crank angle. If not, add the lead row. This is open question Q3, settled by the P8 bench capture.

## What the table does not include

- **Idle (throttle closed):** this map is not used. The ECU uses a fixed 16.3° plus idle-speed corrections ([`simulation.md`](simulation.md)).
- **Cold engine:** `thw_FF0A` adds extra advance below operating temperature, and `overheat_adv` retards above 218 °F.
- **`pwr_ign_trim`:** a selectable trim of 0 to a few degrees (the PWRr input), taken here as 0.
- **Limits:** the total is clamped to about 10° to 64°.

Confidence: the conversion is CONFIRMED in the simulator [EMU:tests/test_sim.py, tests/test_readable.py]. The rpm axis and degrees rest on deltaNE = 180° of crank (LIKELY); the physical meaning of load is LIKELY.
