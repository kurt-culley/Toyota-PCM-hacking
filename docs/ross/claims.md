| Column | Meaning |
|---|---|
| **Scope** | The ECU that the claim is about. `17030` = UK mk1a, `17140` = UK mk1b, `17070` = other mk1, `UK` = UK mk1 in general, `—` = no ECU |
| **Tier** | `A` = how the ECU operates (strategy or structure). The Bluetop possibly has the same strategy, so `cap.bin` can test it. `B` = a calibration value or limit of one ECU. | **17140**, **Bluetop** | The status for that ECU. `—` = not tested on that ECU |
| **Evidence** | One statement for each ECU, with evidence tags and confidence. | Status | Meaning |
|---|---|
| `CONFIRMED` | The ROM or a measurement shows that the claim is true for this ECU |
| `DIFFERS-BY-ECU` | The mechanism exists, but the values or the structure are different on this ECU |
| `PARTIAL` | One part of the claim is confirmed. The evidence statement gives the open part and the test that settles it |
| `CONTRADICTED` | The ROM shows that the claim is not true |
| `NOT-APPLICABLE` | The claim cannot apply (for example, the Bluetop is L-type, not D-type) |
| `PENDING` | Not settled. The evidence statement gives the test that settles it |
