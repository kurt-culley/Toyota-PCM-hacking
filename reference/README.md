# Reference documents

## Summary

This folder holds the data books and articles that the project uses. The Toyota factory manuals are not in the repository, because of copyright. Their facts are in [factory data](../docs/mr2/factory_data.md).

| File | Contents |
|---|---|
| `hd6301_hd6303_series_handbook_1989.pdf` | Hitachi HD6301/HD6303 handbook: instruction set, timers, ports, modes. The documentation calls it "the handbook" |
| `hd6301v1_datasheet.pdf` | Hitachi HD6301V1 data sheet: the DIP-40 pin arrangement |
| `mc6801_reference_manual_1984.pdf` | Motorola MC6801 reference manual. The CPU uses MC6801 instruction timing |
| `ross_lifting_the_lid_mk1_mr2_ecu.pdf` | Jeremy Ross, "Lifting the Lid on the mk1 MR2 ECU". The claims are tested in [claims](../docs/ross/claims.md) |
| `ae86_vast_ignition_system.pdf` | The ignition system of the AE86 4A-GE |
| `ae86_board/` | The schematic of the Bluetop ECU board (ExpressPCB `.sch`), with two pictures (PNG) |

Read a PDF with `pdftotext` or `pdfimages` if the GitHub page does not show it.
